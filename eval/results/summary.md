### Reading the table

- `none` never intervenes, so it scores every should-not-fire case correctly and every should-fire case wrong. It is the floor.
- `exact_dict` handles spellings it was explicitly taught and fails on spellings it was not. Its false interventions are the expensive kind: it rewrites the fruit.
- `phonetic` generalises to unseen spellings *and* declines to act when the evidence does not support it. Both halves are the product.

## Reproducibility

Per-case artifacts under `eval/results/cases/` contain no timing data and are byte-identical across runs on the same commit. After re-running this harness, `git diff -- eval/results/cases` should report **no changes at all**; only the measured latency numbers in `results.json` and in this file will move. Timing is reported once, from the dedicated warm-path measurement above, rather than as 45 noisy single-shot samples.


## Where to look next

Every case has a full artifact in `eval/results/cases/<id>.json` containing the inputs, the expectation, what each strategy actually produced, the memory state at decision time, and the reason the system gave for every span it considered.
